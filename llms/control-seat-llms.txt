# Control Seat

> Control Seat is an AI-native industrial systems integrator building a modern replacement for legacy SCADA (Supervisory Control and Data Acquisition) platforms such as Ignition, WinCC, and FactoryTalk. It designs, builds, deploys, and runs the full industrial control stack — from PLC programming (Allen-Bradley, Siemens, Beckhoff) and HMI/SCADA operator screens to OT/IT networking, historians, and analytics — on a single unified platform. Founded 2025 in San Francisco; backed by Y Combinator (Summer 2026).

This file was generated by the API Evangelist enrichment pipeline from the public Control Seat surface (the provider does not publish its own /llms.txt). Control Seat does not currently publish a versioned public REST API or an OpenAPI description; the platform connects to field systems over OPC UA and MQTT (Sparkplug B) and integrates with AVEVA PI, Ignition, and SQL/time-series databases plus REST.
